Mallar & Guide

Lär dig hur kortsystemet fungerar och använd mallar för att snabbt skapa nya kort.

Den här guiden förklarar alla fält i kortformuläret. Läs den en gång så förstår du hur allt hänger ihop. Varje kort består av en gemensam del (namn, mana, klass…) och en typspecifik del beroende på om det är en minion, stavning eller struktur.

Kortets ID
Format: [SET][LÖPNUMMER]  →  A00001  ·  B00042
  • SET — en bokstav som identifierar kortset. A = Dark Set 01, B = nästa set osv.
  • LÖPNUMMER — fem siffror med nollpadding. A00001, A00002 … A99999.
Verktyget genererar nästa lediga ID automatiskt — du behöver nästan aldrig ändra det.
Gemensamma fält — gäller alla korttyper
FältTypObligatorisk?Förklaring
idtextJaUnikt kort-ID, se format ovan
nametextJaKortets namn som visas i spelet och UI
manaheltal ≥ 0JaManakostnad för att spela kortet. 0 = gratis, max är vanligen 10.
card_classtextJaKlassidentifierare: Dark, Wasteland, The Blue, Forest eller Neutral
card_typetextJaMåste vara exakt minion, spell eller structure — små bokstäver!
descriptiontextKortets regeltext som visas på kortet. Skriv som: "Activate (2): Deal 3 damage."
raritytextBasic · Superior · Supreme · Legendary
keywordstextKommaseparerade nyckelord i VERSALER, t.ex. FLYING, RAPID. Se listan nedan.
draft_tagtextGrupperingsnamn för draft, t.ex. dark_set_01. Används för att hålla set åtskilda.
card_type MÅSTE vara i gemener: minion, inte Minion. Samma för targeting_mode, ability_id osv.
Keywords — nyckelord

Skriv keywords som en kommaseparerad sträng i VERSALER i fältet Keywords. Ordningen spelar ingen roll.

KeywordVad det gör
FLYINGKan bara blockas av FLYING eller REACH. Kan anfalla andra FLYING-minions direkt.
REACHKan blocka FLYING-minions trots att den inte flyger.
RAPIDKan anfalla direkt när den spelas — går direkt till FRONT_LINE utan att vänta en tur.
RANGEIgnorerar alltid blockers och anfaller direkt mot hjälten.
FIRST_STRIKESlår sin skada innan motståndaren i strid. Dör motståndaren av det, svarar den aldrig.
DOUBLE_STRIKEAnfaller två gånger per strid (first strike-skada + normal skada).
TWINSTRIKESlår två separata mål i en och samma attack.
CANT_ATTACKKan aldrig anfalla. Kan fortfarande blockera och använda aktiverade förmågor.
PARRYMinskar inkommande skada. Kan ha värde: PARRY_2 reducerar all skada med 2.
IRON_SKINIgnorerar liten skada (under ett tröskelvärde).
POISONDödar omedelbart allt den skadar, oavsett hur mycket HP målet har.
VAMPIRISMLäker ägaren med samma mängd skada den gör (lifesteal).
INSTANTEnbart stavningar — kan spelas under blockfönstret (som en reaktion).
RESURRECTKan återkallas från graven mot mana-kostnad istället för liv. Normalt kostar det LIV att återliva en minion — en RESURRECT-minion kan spelas ut igen mot sin vanliga mana-kostnad, precis som från handen. Återkommer med full HP utan buffs. Kan återkallas flera gånger.
Exempel: skriv FLYING, RAPID eller DOUBLE_STRIKE, VAMPIRISM i keywords-fältet.
Minionkort — extra fält

Varje minion har stats (attack + health) och kan ha en valfri förmåga.

FältTypFörklaring
attackheltal ≥ 0Skada minionen gör varje gång den anfaller. 0 = kan inte anfalla effektivt.
healthheltal ≥ 1HP-poäng. Når health 0 dör minionen direkt.
subtypetextUndertyp, t.ex. Beast, Undead, Demon, Knight. Visas under kortnamnet.
ability_idtextVilken effekt förmågan gör: deal_damage, draw_card, heal, chain. Tom = ingen förmåga.
ability_triggertextHur förmågan aktiveras. Se listan nedan.
ability_costheltal ≥ 0Extra manakostnad för att aktivera förmågan (utöver kortets grundkostnad).
ability_target_modetextVad förmågan kan riktas mot. Se mållägen längre ner.
ability_targeting_modetextexplicit = spelaren väljer · random = servern slumpar · auto = automatiskt
ability_valueheltalNumeriskt värde: hur mycket skada, hur många kort, hur mycket läkning.
ability_argtextSpecialkostnader. Tom = normal manakostnad. Se ability_arg-sektionen nedan.
ability_trigger — hur förmågan aktiveras
VärdeFörklaring
activateSpelaren klickar manuellt på minionen och betalar kostnaden. Kan aktiveras en gång per tur. Minionen får en lysande glow-effekt för att visa att den är aktiverbar.
on_playTriggar automatiskt när kortet läggs ner från handen. Ingen extra kostnad.
on_deathTriggar när minionen dör (deathrattle). Löser sig efter stridsupplösning.
on_attackTriggar varje gång minionen anfaller.
tomIngen förmåga — lämna tomt för vanliga minions utan ability.
ability_arg — specialkostnader

Normalt är ability_arg tomt och kostnaden räknas i mana via ability_cost. Men med ability_arg kan du sätta en annan kostnad:

FormatVad det görExempel
tomNormal manakostnad via ability_cost''
cost:discard:NSpelaren måste kasta N kort (väljer själv vilka) för att aktiveracost:discard:1
cost:discard_random:NN slumpmässiga kort kastas automatiskt vid aktiveringcost:discard_random:2
Stavningskort — extra fält

Stavningar spelas direkt och försvinner. De har ingen attack eller health — bara en effekt.

FältTypFörklaring
effect_idtextEffekten som sker: deal_damage, heal, draw_card, chain
effect_valueheltalNumeriskt värde: skada, HP, antal kort osv.
target_modetextVad stavningen kan riktas mot. Se mållägen nedan.
targeting_modetextexplicit = spelaren klickar · random = slumpmässigt · auto = automatiskt
schooltextMagiskola för flavortext/gruppering: Shadow, Blood, Void, Storm osv.
effect_argtextExtra konfiguration (samma format som ability_arg ovan). Vanligen tom.
repeat_countheltal ≥ 1Hur många gånger effekten upprepas. 1 = en gång. 4 = träffar 4 mål.
repeat_modetextsame_target = träffar samma mål varje gång · reroll_each_time = nytt slumpmål varje gång
repeat_count + reroll_each_time = AOE/studs-stavning. repeat_count + same_target = multi-hit mot ett mål.
Mållägen — target_mode / ability_target_mode

Samma lista gäller för ability_target_mode (minions/structures) och target_mode (stavningar).

VärdeVad det kan träffa
any_targetValfri minion eller hjälte (vän eller fiende)
target_minionValfri minion (vän eller fiende), inte hjältar
enemy_minionEn av fiendens minions
friendly_minionEn av dina egna minions
enemy_heroFiendens hjälte
friendly_heroDin egen hjälte
enemy_playerAlias för enemy_hero
friendly_playerAlias för friendly_hero
selfKortet/minionen självt — ingen målvalsdialog visas
tomInget mål krävs (t.ex. draw_card som bara drar ett kort)
Strukturkort — extra fält

Strukturer är fasta byggnader på planen. De kan inte anfalla men kan ha passiva triggers och aktiverbara förmågor. De har armor istället för health/attack.

FältTypFörklaring
armorheltal ≥ 1Strukturens "HP". Noll armor = förstörd.
subtypetextT.ex. Tower, Totem, Workshop, Fortification
maintenance_costheltal ≥ 0Mana att betala varje tur för att behålla strukturen aktiv. 0 = gratis.
ability_idtextAktiverbar förmåga (samma effekt-ID som stavningar)
ability_costheltal ≥ 0Manakostnad för att aktivera förmågan
ability_target_modetextMålläge för förmågan
ability_targeting_modetextexplicit · random · auto
ability_valueheltalNumeriskt värde på förmågan
repair_costheltal ≥ 0Mana för att reparera strukturen manuellt
repair_valueheltal ≥ 0Armor som återfås per reparation
trigger_idtextPassiv effekt som triggar automatiskt. Samma effekt-ID som stavningar.
trigger_valueheltalVärde på trigger-effekten
trigger_target_modetextMål för triggern. Vanligen enemy_hero för ett torn som skjuter.
En struktur kan ha BÅDE en aktiverbar förmåga (ability_*) OCH en passiv trigger (trigger_*) samtidigt.
